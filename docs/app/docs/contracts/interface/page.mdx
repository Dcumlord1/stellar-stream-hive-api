# Interface at a Glance

The table below lists every public function across the Stream, Vault, and
Registry contracts in one place. Use it to find, at a glance, who must
authorize a call, what errors to handle, and what events to listen for.

For the full description of each function — parameters, return values, and
prose on why each auth rule exists — follow the link in the **Function**
column to the per-contract reference page. For the payload shape of each
event, see [Stream contract: events emitted](/docs/contracts/stream#events-emitted).

  This table was generated from

  Re-verify against the contract source if the contracts change.

  as design intent, not audited guarantees.
</CalloutBox>
